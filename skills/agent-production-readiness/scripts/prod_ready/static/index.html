    프로토타입 에이전트를 운영 환경(Cloud Run 또는 Agent Runtime)에 배포하기 전에, 영속 세션·Memory Bank, 턴별 루프 가드레일, OTel NO_CONTENT 트레이싱, Non-Root 컨테이너, 최소 권한 IAM/Terraform 템플릿을 자동 주입합니다.

    Play 01 동작 흐름 (로컬 PC 전용)
    Step 1 내 PC에 Skill 설치

    ~/.gemini/config/skills/ 경로에 agent-production-readiness 스킬을 복사합니다.

    Step 2 13개 프로덕션 기준 스캔 & 패치

    Antigravity 프롬프트 또는 prod-ready apply로 agent.py·Dockerfile·terraform/을 하드닝합니다.

    Next 배포 후 Play 02 런타임 검증

    GCP 배포 후 Play 02로 이동해 실제 런타임 환경 JSON이 규격을 충족하는지 최종 검증합니다.

    Step 1

    내 PC에 프로덕션 준비도 스킬 복사 (최초 1회)

    로컬 터미널에서 아래 명령어를 실행하여 Antigravity / Gemini CLI가 인식할 수 있도록 스킬 디렉터리에 복사합니다.

    terminal 내 PC 로컬 터미널에서 실행 
    mkdir -p ~/.gemini/config/skills
cp -r skills/agent-production-readiness ~/.gemini/config/skills/
    Step 2

    내 로컬 에이전트 프로젝트 스캔 및 13개 프로덕션 패치 적용

    Antigravity 대화창에 "이 에이전트 프로덕션 준비도 스캔하고 부족한 부분 패치해줘"라고 입력하거나, 에이전트 프로젝트 폴더에서 아래 CLI를 실행합니다.

    terminal 에이전트 소스 코드 폴더에서 실행 
    uv run prod-ready scan .
uv run prod-ready apply .

    Play 02 Cloud Run & Agent Runtime Interactive Wizard · 약 3분 소요

    배포된 에이전트 설정 JSON을 기반으로 단계별 위자드 점검 및 최종 리포트 생성

    Cloud Run 또는 Agent Runtime의 설정 JSON을 붙여넣으면, JSON으로 검증된 항목과 아키텍처·부하테스트 의도를 확인해야 할 항목을 위자드 형태로 하나씩 점검한 뒤 최종 프로덕션 준비도 리포트와 맞춤형 실행 명령어를 완성해 드립니다.
