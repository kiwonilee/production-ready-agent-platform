    📊 환경별 특징 비교 · 선택 가이드 (Agent Runtime vs Cloud Run vs GKE)

    Agent Runtime, Cloud Run, GKE(Autopilot/Standard · Agent Sandbox · Agent Substrate)의 특징과 선택 기준입니다. 카드를 클릭하면 해당 환경이 선택됩니다.

    ✓

    배포 팁 · 망설여진다면 Cloud Run으로 시작, 고격리·GPU·대규모는 GKE 선택

    코드 변경 없이 세 환경을 오갈 수 있으므로, 우선 비용 부담이 적은 Cloud Run으로 시작하고 장기 문맥 관리가 중요해지면 Agent Runtime, AI 생성 코드 격리·고밀도 멀티에이전트(Agent Substrate, GKE Standard ≥ 1.37 전용 · 대안 Agent Sandbox)·자체 GPU/TPU 모델 서빙이 필요하면 GKE로 단일 명령어(agents-cli scaffold enhance . --deployment-target gke)로 전환할 수 있습니다.

    9-2. 자주 묻는 질문 & 트러블슈팅 FAQ
    

        
    
          Q1. Antigravity CLI에서 agent-production-readiness 스킬을 찾지 못한다고 나와요.
          
    
            
    ~/.gemini/skills/agent-production-readiness/SKILL.md (또는 Global ~/.gemini/antigravity-cli/skills/, 워크스페이스 로컬 .agents/skills/) 경로가 올바른지 확인하세요.
    
          
    
        
    

        
    
          Q2. Antigravity CLI 세션이 끊겼거나 Agent Runtime 배포가 타임아웃되었어요.
          
    
            
    Antigravity CLI는 같은 폴더에서 agy -c 명령으로 직전 대화를 그대로 복구할 수 있습니다. Agent Runtime 배포는 서버 측에서 계속 진행되므로 agents-cli deploy --status로 완료를 확인하세요.
    
          
    
        
    

        
    
          Q3. 배포 중 RUN uv sync --frozen 오류가 발생합니다.
          
    
            
    apply 패치 후 pyproject.toml이 갱신되므로 배포 전 프로젝트 루트에서 uv lock을 1회 실행해 lockfile을 동기화하세요.
    
          
    
        
    

        
    
          Q4. 터미널에서 복사한 JSON을 붙여넣을 때 줄바꿈이 깨져도 되나요?
          
    
            
    네, Web Workbench 백엔드가 터미널 하드 줄바꿈으로 @sha256:... 중간에 들어간 제어문자를 자동으로 정규화하여 파싱하며, GKE의 멀티-JSON 스트림(kubectl get ... -o json 여러 개 연결)도 자동 병합합니다.
    
          
    
        
    

        
    
          Q5. (GKE) agent-gateway.yaml 적용 시 CRD 없음 오류나 PSS restricted 거부·Autopilot 충돌이 발생합니다.
          
    
            
      
              
    • Agent Gateway for GKE CRD 없음: 공식 Agent Gateway for GKE(GCPAgentGateway, GCPBackend, GCPEgressPolicy, GCPAuthzPolicy v1, GCPExtensionBinding v1)는 GKE ≥ 1.37.2-gke.1042000 (Rapid 채널), Preview 리전(us-central1 / europe-west1), Step 0-3의 9개 공식 API, 그리고 리전 proxy-only 서브넷이 선행되어야 합니다.
      • 
              
    • Agent Substrate + Autopilot 충돌: Agent Substrate(ate.dev/v1alpha1)는 GKE Standard ≥ 1.37 전용입니다. Autopilot 클러스터에서는 Standard Pods 또는 Agent Sandbox를 사용하세요.
      • 
              
    • PSS restricted 적용 후 Pod 스케줄링 거부: 반드시 Non-Root securityContext가 반영된 terraform apply(또는 Deployment 업데이트)를 먼저 완료한 뒤 Namespace에 pod-security.kubernetes.io/enforce=restricted 라벨을 부착해야 합니다.
      •
