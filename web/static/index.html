배포 후 런타임 진단 위자드

권한 연동 없이 설정 JSON을 붙여넣고, 항목별 위자드 점검을 거쳐 맞춤형 리포트와 명령어를 생성합니다.

진단 단계 (Step 1 ~ Step 3)
위자드 체크리스트 진단 전
    RUNTIME WIZARD Agent Runtime · Cloud Run · GKE Zero-IAM · 약 3분 소요

    배포된 에이전트 설정 JSON 기반 단계별 위자드 점검 및 최종 리포트 생성

    Agent Runtime, Cloud Run, 또는 GKE(Autopilot/Standard · Agent Sandbox · Agent Substrate)의 설정 JSON을 붙여넣으면, JSON으로 검증된 항목과 아키텍처·부하테스트 의도를 확인해야 할 항목을 위자드 형태로 하나씩 점검한 뒤 최종 프로덕션 준비도 리포트와 맞춤형 실행 명령어를 완성해 드립니다.

    Zero-IAM 읽기 전용 진단: GCP 프로젝트에 어떠한 IAM 권한도 요구하지 않으며 운영 환경을 임의로 변경하지 않습니다. 터미널에서 조회한 설정 JSON만 붙여넣으면 브라우저에서 안전하게 진단합니다.
    체크리스트 v3 점검 범위: 이 위자드는 에이전트 특성에서 나온 항목(세션 · 장기 기억 · 평가 게이트 · 트레이스 · 에이전트 신원 · Agent Registry · Agent Gateway · 사용자 위임 인증 등)만 점수에 반영합니다. 헬스 프로브 · PDB · Non-Root · 사설 연결 · Terraform IaC · 알림 정책 같은 일반 플랫폼 Best Practice는 플랫폼 Skill 참조 권장으로 따로 안내하며, 프로덕션 전에 함께 점검하실 것을 강력히 권장합니다. google/skills · cloud 플랫폼 Skill 보기 ↗
